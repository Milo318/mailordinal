# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or exposed credential. Use
GitHub's private vulnerability reporting for this repository. Include the affected version,
impact, reproduction steps, and any safe mitigation you have identified.

Do not include real email content, API keys, access tokens, or personal data in a report.

## Supported version

Security fixes target the latest release on the default branch.

## Operational warning

The repository ships in demo mode. Do not expose a live TypeSafe API key through an
unauthenticated public deployment. Read `docs/SECURITY_AND_PRIVACY.md` before integrating a
real mailbox or production data.
